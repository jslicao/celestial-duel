# 天弈对决 · 星空背景

独立的全屏背景阶段，尚未加入 Logo、下载、微信二维码或 slogan。

在此目录运行 `npm start`，打开 http://127.0.0.1:4173 。无需安装依赖；Three.js 固定为 0.180.0 并本地随站发布。

拖动浏览天球，悬停／轻触二十八宿的代表星官成员星以显示连线。方向键移动，`[` / `]` 逐个切换星宿，Escape 收起。

星位：D3 Celestial 的 Hipparcos 星表，J2000 坐标，7.5 等及更亮恒星。星宿连线：Stellarium 中国星空文化的 28 个同名代表星官。不是某地实时地平坐标天空，也不将整个宿的所有星官合并成一组连线。色彩、亮度和辉光作艺术化处理；没有随机替代星位。

来源及许可见 dist/data/ATTRIBUTION.txt。数据核对：`npm run check`。
